Kleinanzeigen Ausschlussfilter

Blendet in der Suchergebnisliste von kleinanzeigen.de alle Anzeigen aus, die von dir festgelegte Begriffe enthalten. Alles läuft lokal in deinem Browser, es werden keine Daten gesendet.

Installation

  1. Userscript-Manager installieren: Tampermonkey oder Violentmonkey.
  2. Auf den Button klicken und die Installation bestätigen:

    Filter installieren
  3. Eine Suche auf kleinanzeigen.de öffnen – unten rechts erscheint das Feld „Ausschlussfilter“.

Bedienung

  • Begriff eingeben + Enter (mehrere mit Komma trennen).
  • * als Platzhalter, z. B. ersatz*teil.
  • Regex mit Schrägstrichen, z. B. /\bdefekt\b/.
